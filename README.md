# Personal Portfolio

Check out some of my recent projects at [Tuong Luu](https://luut189.github.io/)

## About

Hello! I'm Tuong Luu, a web developer passionate about creating modern and interactive web experiences. This portfolio website was originally built with plain HTML, CSS, and TypeScript using Vite as a bundler.

The initial version of the website was more of a playground where I could experiment and learn new things in web development. Recently, I renovated the website using React and TailwindCSS, and incorporated Framer Motion for some smooth animations to make the site more dynamic and visually appealing.

## Technologies & Tools Used

- **Frontend**: TypeScript, React, TailwindCSS, shadcn/ui
- **Animation**: Framer Motion
- **Version Control**: Git, GitHub
